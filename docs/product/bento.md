# Bento (o chat com os agentes)

Rota: `/chat`. É aqui que você fala com o Bento e com os outros agentes especialistas (Otto, Jarbas, Suzy).

- Na tela inicial do chat, cartões dos agentes pra você escolher com quem falar, ou deixar em "AUTO" pra o sistema escolher o agente certo pela sua pergunta.
- Dentro de uma conversa já aberta, dá pra trocar de agente no meio do papo pelos chips no topo.
- Bento é o agente de conhecimento geral: informações de clientes, dúvidas sobre como usar o próprio DesigualOS, ideias. Otto é o diretor criativo (copy, peças, campanha). Respostas podem errar — sempre valide informação crítica antes de usar com o cliente.
- "Novo chat" no menu lateral começa uma conversa do zero.

Pergunta típica: "com quem eu falo pra tirar dúvida sobre um cliente?" → Bento, aqui. "Quem escreve a legenda/peça?" → Otto.
