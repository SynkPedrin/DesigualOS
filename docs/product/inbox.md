# Inbox

Rota: `/inbox`. É onde ficam as conversas com clientes e contatos (WhatsApp).

- Três colunas: lista de conversas (filtros Todas/Não lidas/Clientes/Contatos + busca + botão "Nova conversa"), a conversa aberta no meio, e um painel de contexto à direita.
- Um link direto pra uma conversa específica abre ela automaticamente (usado por notificações).
- A aba "Contatos" do menu lateral abre esta mesma tela, já filtrada pra mostrar a lista de contatos de WhatsApp (nome + telefone) em vez das conversas.

Pergunta típica: "onde eu respondo o cliente no WhatsApp?" / "onde fica a lista de contatos?" → aqui (a segunda é a aba "Contatos" desta mesma tela).
