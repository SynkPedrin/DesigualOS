# Pipeline

Rota: `/pipeline`. Quadro estilo Kanban para oportunidades, tarefas ou carga de trabalho por colaborador.

- "Nova pipeline" cria um quadro novo (escolhendo o tipo — por exemplo "Tarefas", que usa os status reais do ClickUp como colunas). "Novo cartão" adiciona um item ao quadro. "Configurar" ajusta as colunas.
- Cartões são arrastáveis entre colunas; num quadro de "Tarefas", mover o cartão também atualiza o status da tarefa no ClickUp.
- Clicar num cartão ligado a um cliente real abre um detalhe com abas (Visão geral, Demandas, Tarefas, Arquivos, Anexos).

**Importante:** hoje esta tela ainda não tem uma API própria por trás — fora do modo de demonstração, ela mostra "Pipeline ainda não está conectada" em vez de dados reais. `[CONFIRMAR]` se isso já mudou antes de prometer o Pipeline como ferramenta de uso diário.
