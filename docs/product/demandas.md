# Demandas

Rota: `/demands`. Lista de pedidos de trabalho recebidos dos clientes.

- Filtros por status: Todas/Novas/Em briefing/Em produção/Concluídas/Canceladas.
- Cada linha mostra título, cliente, há quanto tempo foi pedida e o status; clicar abre o detalhe da demanda.
- Uma demanda nasce de dentro de uma conversa no Inbox (botão "Criar demanda" na conversa com o cliente) ou é lançada manualmente pelo time — esta tela de lista não tem botão de "nova demanda" própria.

Pergunta típica: "onde eu vejo os pedidos que os clientes mandaram?" → aqui. "Como eu crio uma demanda?" → a partir de uma conversa no Inbox.
